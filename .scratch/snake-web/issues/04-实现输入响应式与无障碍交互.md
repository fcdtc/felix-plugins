# 04: 实现输入、响应式与无障碍交互

**What to build:** 为现有游戏接入统一输入适配层，支持方向键、WASD、屏幕方向按钮、暂停/继续和重新开始，并完成窄屏触控布局、键盘焦点、ARIA 状态反馈和非颜色信息表达，使桌面与移动端均可操作。

**Blocked by:** 03 / 渲染棋盘并接入游戏循环

**Status:** ready-for-agent

## Scope

- 新增 `src/input.js`，只负责把键盘和按钮事件映射为规则引擎/runtime 的领域动作。
- 方向键与 WASD 均可控制；空格可暂停/继续；页面按钮可完成四方向、暂停/继续与重开。
- 对游戏相关方向键和空格阻止页面意外滚动，但不拦截无关按键或输入控件中的正常操作。
- 输入层不自行判断反向是否合法；同一 tick 多次输入仍由 `game-state.js` 的单一规则决定。
- 可以对 `index.html`、`styles.css` 和薄 `main.js` 做既定集成修改，但保持已有 DOM hooks 稳定。
- 页面在窄屏无水平滚动，棋盘保持正方形，触控按钮尺寸可操作；桌面布局不过度拉伸。
- 所有控件有可访问名称和可见焦点，开始、分数变化、暂停、继续、game-over 与重开通过 `aria-live` 文本表达；Canvas 不是状态信息的唯一来源。
- 尊重 `prefers-reduced-motion`，不添加非必要动画。

## Acceptance Criteria

- [ ] 桌面方向键/WASD、空格和屏幕按钮均能完成对应操作，同一 tick 连续输入不能造成即时反向，暂停/继续始终只有一个循环，重开完整重置当前游戏；约 400px 窄屏无水平溢出且按钮可触控，键盘焦点、Canvas 名称、状态与分数播报可感知，全部既有 Node 测试继续通过。
