# 02: 实现确定性游戏规则引擎

**What to build:** 实现与 DOM、Canvas、计时器和存储完全分离的贪吃蛇规则引擎，定义可测试的状态模型与状态转换，覆盖开始、转向、推进、增长、计分、食物生成、碰撞、暂停、继续和重开，并通过可注入棋盘尺寸与随机源保证确定性测试。

**Blocked by:** 01 / 搭建 Web 应用骨架

**Status:** ready-for-agent

## Scope

- 新增 `src/game-state.js` 与 `tests/game-state.test.js`，保持公开 API 小而明确。
- 初始棋盘为 20×20，调用方可为测试注入其他合法尺寸和随机函数。
- 实现固定格移动、一次 tick 最多一个有效转向、禁止直接反向、吃食物增长一格并增加 10 分。
- 食物只能出现在空格；处理随机值边界和棋盘无剩余空格的情况。
- 撞墙或撞自身后进入 game-over，后续 tick 不再改变蛇的位置。
- 暂停时 tick 不推进；继续恢复推进；重开产生合法初始蛇、0 分和新食物。
- 此模块不得查询 DOM、Canvas、`window`、真实计时器或 `localStorage`。

## Acceptance Criteria

- [ ] Node 内置测试以固定输入独立验证初始状态、正常移动、每 tick 单次转向、反向保护、进食增长与加 10 分、食物不落在蛇身、墙体碰撞、自身碰撞、暂停/继续、game-over 后静止和完整重开，全部通过且规则模块不依赖浏览器全局。
