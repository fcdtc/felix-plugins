# 05: 持久化最高分并完成端到端验收

**What to build:** 实现可安全降级的本地最高分持久化，补齐项目使用文档，并对从开始、移动、得分、暂停/继续、失败到重开的完整游戏流进行最终回归，确保 `examples/snake-web/` 可按规格独立运行和验证。

**Blocked by:** 04 / 实现输入、响应式与无障碍交互

**Status:** ready-for-agent

## Scope

- 新增 `src/storage.js` 与 `tests/storage.test.js`，通过注入的 Storage-like 接口读写最高分。
- 缺少存储、读写抛错、空值、非数字、负数或损坏数据时安全回退为 0，不阻断游戏。
- 仅当当前分数超过已知最高分时写入；刷新页面后可读取合法最高分。
- 在薄 `main.js` 中连接最高分状态与 UI，不把游戏当前分数的所有权移出 `game-state.js`。
- 新增 `examples/snake-web/README.md`，记录技术边界、本地静态服务命令、浏览地址、测试命令、键盘/触控操作和支持范围。
- 运行完整 Node 测试，并手工验证桌面和约 400px 窄屏下的开始、移动、得分、暂停、继续、game-over、重开与刷新后最高分。
- 只修复整链集成缺陷，不新增关卡、难度、声音、主题、网络或其他超出规格的玩法。

## Acceptance Criteria

- [ ] 合法最高分可跨刷新保留，存储不可用或损坏时页面回退为 0 且游戏继续可玩；`node --test examples/snake-web/tests/*.test.js` 全部通过，README 中的 `python3 -m http.server 8000 --directory examples/snake-web` 与测试命令可复现，桌面和窄屏完整游戏流、焦点与状态播报均通过最终验收，且未引入第三方依赖或规格外功能。
