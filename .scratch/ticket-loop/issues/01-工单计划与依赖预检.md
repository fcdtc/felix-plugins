# 01: 工单计划与依赖预检

**What to build:** 用户可以对 issues 目录、编号范围或显式工单列表执行只读计划，得到结构化的冻结 Manifest 预览。系统区分 Task Ticket 与 Wayfinder Ticket、解析状态与依赖、验证依赖图，并返回确定的初始 Frontier，全程不调用 Claude、不创建 Session、不修改工单。

**Blocked by:** None (can start immediately)

**Status:** done (2026-09-15, c87443a)

- [x] 支持 issues 目录、编号范围和显式工单文件三种输入，并将所选工单冻结为 Manifest 预览。
- [x] 只接受符合命名约定且具备 Task Ticket 必要字段的文件，兼容加粗与裸状态字段，并排除含裸 `Type:` 的 Wayfinder Ticket。
- [x] 识别 `ready-for-agent` 与 `done (...)` 状态，且字段缺失或重复时 fail closed。
- [x] 只从 `Blocked by` 字段解析 blocker 编号，支持 None、单 blocker、多 blocker 和带标题后缀的写法。
- [x] 验证缺失 blocker、重复编号、自依赖和依赖环。
- [x] Manifest 外的 Task Ticket 仅在 done 时满足依赖，Manifest 外的 Wayfinder Ticket 仅在 resolved 时满足依赖。
- [x] 多个 Frontier 候选存在时返回编号最小者。
- [x] 输出单个带 schema version 的结构化 JSON，并正确处理中文、空格和绝对路径。
- [x] 计划过程不调用 Claude、不创建 Session、不写工单，也不改变 Git 状态。
- [x] 通过 CLI 外部行为测试覆盖成功计划及所有拒绝场景。
