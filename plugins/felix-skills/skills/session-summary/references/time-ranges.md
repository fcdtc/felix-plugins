# 时间范围规则

## 输入与映射

全部日历范围和输出时间统一使用**北京时间（UTC+08:00）**。相对时间以扫描开始时的北京时间日期为基准，与电脑系统时区无关，不需要传时区参数。

| 用户输入 | 脚本参数 | 请求范围 |
|---|---|---|
| 不指定、今天／今日 | `--period today` 或省略 | 今天零点到明天零点 |
| 昨天／昨日 | `--period yesterday` | 昨天零点到今天零点 |
| 本周／这周 | `--period this-week` | 本周一零点到下周一零点 |
| 上周 | `--period last-week` | 上周一零点到本周一零点 |
| `YYYY-MM-DD`、指定某日 | `--date YYYY-MM-DD` | 该日零点到次日零点 |
| `A 至 B`、`A 到 B`、`A..B`（日期） | `--start A --end B` | A 零点到 B 次日零点，包含两端日期 |
| 明确起止时刻 | `--start ISO8601 --end ISO8601` | 起始时刻含，结束时刻不含 |

`--date`、`--period`、`--start/--end` 三种选择器互斥。`--start` 和 `--end` 必须成对。日期与时刻可混合：日期开始取当天零点，日期结束取次日零点；时刻结束本身不含。ISO8601 未附偏移时按北京时间解释；带偏移时按绝对时刻解析，再转为北京时间展示。

自然语言传给 Skill，由执行代理转换为上述确定参数；脚本自身只接收结构化参数。用户说“最近三天”等其他明确范围时，同样计算成起止参数，并在报告中说明实际范围。只有“前几天”等无法确定长度的输入才需要追问。

## 截止与周语义

- 请求范围始终开始含、结束不含。
- 最终实际结束是请求结束与扫描开始时间（或为重查指定的 `--until`）的较早者。即使整周尚未结束，本周总结也只覆盖截至扫描的部分。
- “本周”是周一开始的自然周，不等于滚动七天；“最近七天”默认含今天的七个日历日，若用户说“过去 168 小时”则按精确时刻计算。
- 昨天、上周和已结束区间覆盖完整历史范围；未来部分不生成活动，完整未来范围报告尚未发生。
- 日和自然周的边界统一取北京时间零点。

## 示例

```text
/felix-skills:session-summary 昨天
/felix-skills:session-summary 本周
/felix-skills:session-summary 2026-11-12
/felix-skills:session-summary 2026-11-01 至 2026-11-12
/felix-skills:session-summary --start 2026-11-12T09:00:00+08:00 --end 2026-11-12T18:00:00+08:00
/felix-skills:session-summary 上周 --output /absolute/path/to/weekly-summary.md
```

多日总结的推进时间线显示日期和时刻；跨年时显示完整日期。会话计数在整个范围内唯一，仅用于内部核对，不生成每日统计或会话清单。
