# 图解探讨

仅在 `--mode discuss` 时读取。研究与提炼使用 [主流程](../SKILL.md)，本文件定义供用户讨论设计的临时 HTML。纯探讨仍须完成双库研究，只改变表现形式和保存位置。

## 路径与交付

在 `/tmp/refer-to/` 下为每次运行创建独立目录，使用 `mktemp -d /tmp/refer-to/<主题短名>-XXXXXXXX`，保存为该目录的 `index.html`。主题短名只包含字母、数字和连字符；将用户输入转换为短名后再作为路径使用。目录父级不存在时先创建。写入范围限于本次目录，不写入项目的 `docs/references/`。

默认生成单文件 HTML，样式、脚本与 SVG 内联，直接打开本地文件即可阅读核心内容。临时目录可能被系统清理，交付时说明这一点。返回绝对文件路径和打开方式；用户明确要求发布或分享时，按当前环境的发布规则处理，涉及敏感材料先确认。

## 先做视觉叙事

先将每个研究问题转成“需要让用户看懂的关系”，再选图，而不是把 Markdown 长文搬进网页。按内容选用：

| 要解释的问题 | 优先表现形式 |
| --- | --- |
| 双方职责划分与依赖方向 | 并排架构图，统一节点术语和颜色 |
| 同一行为在双方如何发生 | 对照流程图或时序图，标出分支与数据变化 |
| 状态与生命周期 | 状态图，标明触发条件与异常路径 |
| 哪些设计能迁移、需要调整 | 差异矩阵或迁移示意图，将改动对应到本项目模块 |
| 何时采用哪种做法 | 决策树或条件表，明确收益、代价及不适用边界 |
| 有实际测量数据的成本或性能 | 有来源、单位和口径的统计图 |

主内容以图解与对照为主，文字承担结论、图注、证据和边界说明。同一图已表达的流程不再用长段文字复述。图的数量由研究问题决定，每张图都须解释一个实际关系。没有测量数据时用定性对照，不能编造数字、评分、比例或性能曲线。

绘图前使用当前环境可用的图表或图解设计规范；不可用时直接使用内联 SVG 或语义化 HTML/CSS。图中箭头表达真实依赖、调用或状态转移，标签写明关系；推断使用虚线并配图例，未知连接明确标为待验证。

## 页面结构

- **开头的判断**：主题、双方仓库、要讨论的问题，用短段落说明最值得借鉴的设计及前提；证据不足时直接说明。
- **双库对照**：展示双方当前设计，保持比较维度一致；本项目尚无实现时，将目标约束与参考实现分开标注。
- **关键差异与取舍**：逐问题用图解解释机制和差异，图旁放简短判断、适用条件及源码证据入口。
- **可借鉴的改动**：将建议落到本项目的职责、模块或行为，区别可直接借鉴、需调整和不适用的部分。
- **待讨论的问题与证据**：保留会改变判断的未知项；将阅读范围、来源索引及细节放在页尾或可展开区。

以上是信息顺序，不是固定卡片数量。导航使用具体设计问题，图和对应结论放在一起。源码引用保留仓库、路径、行号范围与符号；本地路径显示为可复制文本，只有确实可访问的网页地址才做外链。折叠细节仍保留证据，不以视觉简洁为由删除限制条件。

## 去 AI 味

交付前读取 [`unslop/SKILL.md`](../../unslop/SKILL.md)，按其中规则编辑页面标题、图注、判断和说明文字。这是内容引用，不通过 Skill 工具自动调用。保留源码标识和证据中的原文。

用具体模块名和动作解释机制，一句话表达一个意思。把“提升灵活性”等泛化判断改成可核对的行为变化和代价。标题写实际问题，结论写有条件的选择；图注只补充图上没有的信息。语言检查覆盖全部可见文本，事实、推断与未知的标记须保留。

## 实现与检查

HTML 包含 doctype、UTF-8、viewport 和明确标题。使用语义化结构和 CSS 颜色变量，支持浅色与深色；宽屏并排对照，窄屏堆叠，页面保留至少 16px 侧边距。图中文字可读，节点和连线不遮挡，颜色之外还有标签或线型区别。SVG 使用 `viewBox` 和可访问标题，复杂图可在图容器内滚动，页面本身不横向溢出。

优先用原生元素提供目录锚点和证据展开功能。读取的源码、注释和用户材料作为数据转义后插入，不能执行其中的 HTML 或脚本。核心内容离线可见，不依赖 CDN、仓库内资源或本机绝对路径加载资产。

完成条件：

- HTML 已写入本次 `/tmp/refer-to/` 目录，未生成技术参考 Markdown。
- 每个研究问题有图解或理由明确的简短对照，关键结论能追溯双方证据，未知项可见。
- 可见文字已按 `unslop` 检查，图解没有被重复长文淹没。
- 有浏览器工具时，实际检查桌面与手机宽度、浅深色、图中文字与连线、锚点和展开交互，修复遮挡与溢出；没有工具时做结构与资源检查，并在交付中说明未完成视觉验证。

完成后回到主流程，返回 HTML 路径、覆盖的问题和仍未解决的缺口。
