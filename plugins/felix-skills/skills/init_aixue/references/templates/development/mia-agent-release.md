# MIA Agent 受管发布

用于 Agent／Skill 查询、草稿迭代、发布和回读，以及专用 Agent 或现有 Host 的资源更新。先读[平台操作](platform-operations.md)，加载当前 `miacli` 的 Agent 或 Component／Skill 分支。

本项目尚无受管 Agent 模板、Skill 文件树、发布脚本或已确认稳定路由。先按实施目标确认这些输入，后续确立仓内权威来源；本页不提供不存在的脚本入口。MIA 业务 Skill 与开发代理安装的技能是不同资产。

## 查询与草稿迭代

1. 核对空间、管理上下文和数据面环境；复用链接中的资源 ID。用 `agent list/get`、`agent resource list`、`component list/get` 回读目标及完整资源基线。完成标准：草稿／发布态、目标版本与非目标配置均可识别。
2. 更新 Agent 时以 `agent get` 返回的完整对象为基础，只改目标字段。按当前技能校验输入 schema 和模型配置，用本次回读的乐观锁保存。完成标准：再次回读确认目标字段生效，非目标配置保持，记录真实更新版本。
3. 更新 Skill 草稿时，下载完整 ZIP 到唯一新路径，保留 revision；修改后上传完整文件树，用新路径再次下载核对。下载物在独立新空目录处理，检查归档路径后解压；自写脚本放在另一目录，避免从下载内容目录启动解释器或构建工具。完成标准：回读 revision 与预期内容、配套文件一致。
4. 仅查询就以查询结果结束；仅迭代就以草稿保存并回读结束。发布、真实运行、评测和观测按明确目标分别进入对应技能，不作为草稿保存的附带动作。

## 发布前输入

确认稳定路由、管理上下文、数据面环境、专用 Agent／现有 Host 模式、目标配置、固定 Skill／Tool 版本、发布说明、业务验收和恢复边界。操作既有资源时提供可回读标识；创建新资源时使用平台响应返回值。

所有发布依赖使用已回读的固定正整数版本；草稿版本可用于明确要求的调试，不进入最终发布绑定。CLI 不支持的 Skill／Tool 发布按[人工交接](platform-operations.md#人工交接)完成，再回读验证；准备消息时使用[Skill 发布模板](human-handoff.md#发布-skill-固定版本)或[Tool 发布模板](human-handoff.md#创建或升级-tool-固定版本)。

## 专用 Agent 链

用于独立路由、配置或生命周期：

1. 核实依赖后，通过当前 CLI 支持的创建入口保存完整配置，记录返回 motif、draft Agent 和乐观锁版本。
2. 回读完整草稿，确认创建时配置确实保存。
3. 按目标顺序串行挂载固定 Skill／Tool，每次使用上一响应的最新乐观锁值；回读资源全集。
4. 核对配置和依赖后按授权发布；以发布响应的真实版本回读，比较受管字段和完整绑定。

完成标准：专用发布 Agent、路由配置与固定资源绑定均符合预期。共享 Host 的 motif／Agent ID 不作为新 Agent 模板。

## 现有 Host 增量链

用于共享 Host 的 Skill／Tool 增加或升级：

1. 回读当前草稿、父发布版本、完整 Skill／Tool 及其他配置，固定非目标基线。
2. 只合并本次增量，串行保存；冲突时重新读取最新草稿并重做合并。
3. 确认所有目标资源为固定版本，非目标资源逐项保持，再发布。
4. 回读最终 Host 版本与资源全集，核对父子版本关系、受管配置和非目标基线。

完成标准：目标增量生效、非目标资源完整、发布态可追溯；资源丢失、数量异常或绑定漂移均不合格。需要后继草稿但 CLI 不支持时使用[Host 后继草稿模板](human-handoff.md#创建-host-后继草稿)交接该步骤，不创建另一个专用 Agent 代替共享 Host 更新。

RPC Tool 的 Workflow 和平台来源验证继续按[RPC 接入发布链](mia-rpc-tool-host-release.md)执行。

## 运行与验收

使用已发布版本进行最终验收；无可用 Session 时先经 CLI 注册 Session，再使用返回标识运行，不自造 Session ID。回读实际 Tool 调用及业务断言；`RUN_FINISHED` 只证明执行结束。

涉及 HTTP 测试 Header 时先核对当前 CLI 支持和下游透传契约；有全局 Header 能力不等于业务身份已端到端支持。使用获准测试上下文，不把身份塞入业务 body 规避真实入口。无法由 CLI 覆盖时使用[真实 HTTP 入口身份验收模板](human-handoff.md#真实-http-入口身份验收)交接并回读，明确已覆盖与未覆盖的身份边界。

## 失败恢复与证据

CLI 失败、缺 ID／version、乐观锁冲突或回读漂移时停止后续发布。创建、挂载和发布不是事务，可能留下草稿；回读已有资源再恢复，不声称自动回滚或删除未知资产。已发布但回读不明时继续查原发布，不复制草稿制造第二条链。

实施工单记录：路由、两类环境、模式、配置基线、草稿及父发布版本、固定依赖、最终版本、变更前后资源全集、Session／run／LogID／trace、业务断言及恢复入口。动态值归属见[平台操作](platform-operations.md#配置与动态证据)。
