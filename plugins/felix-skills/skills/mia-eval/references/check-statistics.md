# 预期与实际检查统计

## 工具遵循率

**工具遵循率 = 所有选定案例的 checks 中状态为 pass 的条数 / 所有选定案例的 checks 总条数。**

这里的每条检查，就是详情页“预期与实际检查”表中的一行：检查要求、应该怎么做、实际做了什么、状态。

- 统计 manifest 选定的全部 case；范围外报告不计入。
- 统计每个 case 的完整 `checks` 数组，包括总检查和逐项业务检查；不按检查 ID、工具名或类型筛选，也不只取 `checks.tool_usage`。
- 每条 pass、fail、unknown 各计一次。pass 进入分子；fail 与 unknown 只进入分母。不同 case 中相同 ID 的检查分别计数。
- 汇总全部条数后计算，不平均各 case 比例。例如一个 case 有1条 fail，另一个有9条 pass，结果为9/10=90%，不是50%。
- 没有任何检查时为 N/A，不显示100%。
- 缺报告或缺必要检查时，只展示已知检查通过占比、已知条数及缺项 case 数，不补造未知条目，不声称完整工具遵循率。已有 unknown 检查仍计入分母，不等于该条不存在。

工具遵循率只汇总检查状态，不用 case 的 verdict 覆盖每条状态，也不受逐调用结果替换。增加检查行必须是本轮真实适用要求，不能为提高比例重复或拆出无意义检查。

## 与其他指标分开

| 指标 | 统计单位 |
| --- | --- |
| 工具遵循率 | 详情页全部预期与实际检查条目 |
| 工具正确使用率 | 全部实际工具调用，按[逐调用判定](tool-call-scoring.md)统计 |
| 设计遵循率、流程完成率、结束时机正确率 | 全部选定案例，各轴独立判定 |
| 顺畅通过率 | 遵循设计、流程完成且没有恢复或挣扎的案例 |

`checks.tool_usage` 仍是必要案例检查之一，参与 case 整体判断，并作为普通一条计入工具遵循率；它的通过 case 数不是工具遵循率，也不是工具正确使用率。

## 模板与输出

汇总的“综合表现”显示工具遵循率的 pass / 全部检查条数，以及 fail、unknown 数；工具正确使用率另外显示实际调用的计数，写明两者分母不同。

汇总不展示“覆盖率（完整 / 全部样本）”表，包括可判定分析、JSON报告、原始case页面、设计基线、调用轨迹和思考证据六行。证据完整性仍用于判定，详情页“覆盖与限制”和私有JSON保留；删除展示不取消取证及完整性校验。

改模板不自动重写历史报告。不改旧检查状态或版本号，不把重新渲染冒充新审计；更新已有报告需用户明确要求。
